## Técnica ensinada

- **Oscilador:** sine = 1 frequência; saw = fundamental + harmônicos; o timbre é o BALANÇO dos harmônicos
  (*"what it sounds like is going to be different because of these overtones"*).
- **Filtros com papel definido:** LP = brilho ("adding or removing brightness"); **BP = sweeping**
  (*"typically I associate band-pass with sweeping sounds… imagine using this for a riser"*); **HP = corpo**
  (pads/leads agudos — controla-se quanto corpo entra); **notch = movimento em som distorcido**
  (*"notch filters are not super interesting on clean waves, but you see them used a lot on things that are
  heavily distorted… typically like neuro sound design"*).
- **ADSR com 3 arquétipos:** pluck (attack curto + decay curto até zero) · **instrumental** (*"it's going to
  have a bit of attack and decay and generally sustain somewhere lower… it's probably not going to have
  maximum sustain"*) · swell (attack/decay longos, nota longa). Regra: *"if you're trying to design
  something that sounds instrumental, think about the fact that it's going to have a bit of attack and decay
  and generally sustain somewhere lower"*.
- **Env vs Mod:** `env` = envelope (toca 1× por nota); `mod` = LFO (loopa). Knob "mod" = quanto o modulador
  afeta o parâmetro. **Dois amounts** (no ponto de atribuição × no modulador) — o geral serve quando o LFO
  ataca vários destinos.
- **Unison Classic = espessura/largura** (mais voices = mais grosso); **Glide + mono = bend entre notas**.
- **Cirurgia de preset:** pluck→pad e pad→pluck trocando-se só envelopes (resetar LFO→filter, puxar
  envelope 2 para pluck shape, subir sustain/attack para pad). *"We've clearly changed the sound from a
  pluck to something that's now more like a sweep or a pad"*.
- **Diferenças de synth:** Operator = envelope dedicado POR oscilador (e o LFO dele aponta para pitch por
  default); Serum = envelope 1 é amp, todo o resto é **drag-and-drop** com amount e matrix visível.

## Tradução / valor de estudo

Aula de fundação — fixa o vocabulário de síntese usado em todo o acervo. Pontos mais úteis para psytech:
o arquétipo **instrumental (sustain médio-baixo)** como ponto de partida para timbres de percussão orgânica
de madeira, e o papel do **notch = movimento pós-distorção** (relaciona-se com o estudo de neuro sound
design do vídeo `tfncDL3iIeI`).

## Notas de aplicação

- Para timbres orgânicos de percussão: envelopes com sustain baixo + attack curto soam mais "instrumentais"
  do que pads de sustain alto.
- Notch só faz sentido em camada saturada; em onda limpa ele quase não se ouve.
