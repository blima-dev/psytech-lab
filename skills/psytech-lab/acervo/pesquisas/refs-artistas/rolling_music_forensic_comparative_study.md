# Rolling Music — Estudo Forense Comparativo (12/09/2026)

> Questão de estudo: a linguagem da gravadora Rolling Music (Gazolla, Petrix, TLGC, Farhy) encaixa em um projeto psytech minimal? Caso não: o inverso — do tech house para o psy, não do psy para o tech house.
> Base de medição: perfis de groove de 29 loops medidos, biblioteca de groove de tech house e medições anteriores das faixas de referência usadas no comparativo da seção 2.

## 3. Veredito de encaixe (INFERÊNCIA — ouvido decide)

1. **Allert (Petrix) é o encaixe mais direto**: 124 BPM, ghosts 30/32, quase reto — é psytech com bateria presente. Os grooves dele já soam psytech.
2. **Breakdown (Gazolla+Petrix)**: o pull 0.61/0.77 é a malandragem a importar — nas percussões e camadas de madeira, não no motor (chão kick+baixo).
3. **O selo confirma a regra geral**: chão reto (psy) + malandragem nas camadas (tech house) = a fusão. O "inverso" (tech house → psy) já tem precedente no próprio selo: a faixa quase reta com hipnose de ghosts (Allert, 30/32) já leva a linguagem psy para dentro do tech house.
4. **O que NÃO encaixa direto**: o kick de tech house — peso e envelope diferentes do psy; usar como textura/layer, não como kick principal.
